# Other Sequence Analysis Tools 


(openspliceai)=
## [OpenSpliceAI](https://github.com/Kuanhao-Chao/OpenSpliceAI)

OpenSpliceAI provides an efficient modular implementation of SpliceAI, enabling easy retraining across nonhuman species. 


**Categories:** splice-site-prediction, rna-seq, deep-learning  
**Publication:** [PMC12575001](https://pmc.ncbi.nlm.nih.gov/articles/PMC12575001/)



(splam)=
## [Splam](https://khchao.com/splam/)

Splam is a deep-learning-based splice site predictor that improves spliced alignments. 


**Categories:** splice-site-prediction, rna-seq, deep-learning, alignment  
**Publication:** [PMC11406845](https://pmc.ncbi.nlm.nih.gov/articles/PMC11406845/)



(psauron)=
## [PSAURON](https://github.com/salzberg-lab/PSAURON)

PSAURON assesses protein annotation quality across a broad range of species. 


**Categories:** protein-annotation, annotation-quality  
**Publication:** [PMC11704789](https://pmc.ncbi.nlm.nih.gov/articles/PMC11704789/)



(conterminator)=
## [Conterminator](https://github.com/martin-steinegger/conterminator)

Conterminator identifies contaminated entries in GenBank through large-scale sequence screening. 


**Categories:** contamination-detection, quality-control, genome-analysis  
**Publication:** [PMC7218494](https://pmc.ncbi.nlm.nih.gov/articles/PMC7218494/)



(wheeler-graph-toolkit)=
## [Wheeler Graph Toolkit (WGT)](https://github.com/Kuanhao-Chao/Wheeler_Graph_Toolkit)

WGT provides tools and algorithms for recognizing, visualizing, and generating Wheeler graphs. 


**Categories:** genome-graphs, graph-algorithms, visualization  
**Publication:** [PMC10415921](https://pmc.ncbi.nlm.nih.gov/articles/PMC10415921/)



(brca-gene-testing)=
## [BRCA gene testing](https://github.com/salzberg-lab/BRCA-diagnostic/wiki)

A computational screening test that takes raw DNA sequence data from a whole-genome sequence of an individual human and tests for each of 68 known mutations in the BRCA1 and BRCA2 genes.


**Categories:** variant-detection, clinical-genomics, cancer  
**Publication:** [PMC3218655](https://pmc.ncbi.nlm.nih.gov/articles/PMC3218655/)



(dive)=
## [DivE](https://github.com/salzberg-lab/dive/wiki)

A software tool to find regions that evolve at a slower or faster rate than the neutral evolution rate in any clade of a phylogeny of a set of very closely related species.


**Categories:** comparative-genomics, phylogenetics, evolutionary-analysis  
**Publication:** [PMC3143108](https://pmc.ncbi.nlm.nih.gov/articles/PMC3143108/)



(elph)=
## [ELPH](https://github.com/salzberg-lab/elph/wiki)

A motif finder based on Gibbs sampling that can find ribosome binding sites, exon splicing enhancers, or regulatory sites.


**Categories:** motif-finding, regulatory-elements, sequence-analysis  
**Publication:** [PMC1892810](https://pmc.ncbi.nlm.nih.gov/articles/PMC1892810/)



(fqtrim)=
## [fqtrim](https://github.com/gpertea/fqtrim/wiki)

A software utility for filtering and trimming high-throughput next-generation sequencing reads.


**Categories:** read-filtering, read-trimming, quality-control  



(insignia)=
## [Insignia](https://insignia.cbcb.umd.edu/)

A comprehensive system for finding unique DNA sequences that can be used to identify any bacterial or virus species or strain. The database contains more than 13,000 species and strains.


**Categories:** species-identification, strain-identification, bacterial-genomics, viral-genomics  
**Publication:** [PMC1868776](https://pmc.ncbi.nlm.nih.gov/articles/PMC1868776/)



(phymmbl)=
## [PhymmBL](https://github.com/salzberg-lab/phymmbl/wiki)

A one-stop system for taxonomically classifying metagenomic short reads.


**Categories:** metagenomics, taxonomic-classification, sequence-classification  
**Publication:** [PMC3319356](https://pmc.ncbi.nlm.nih.gov/articles/PMC3319356/)



(repeatfinder)=
## [RepeatFinder](https://www.cbcb.umd.edu/software/RepeatFinder/)

An older system for finding and characterizing repetitive sequences in complete and partial genomes.


**Categories:** repeat-analysis, genome-analysis, genome-annotation  
**Publication:** [PMC55324](https://pmc.ncbi.nlm.nih.gov/articles/PMC55324/)



(scimm)=
## [SCIMM](https://www.cbcb.umd.edu/software/scimm)

A tool for unsupervised clustering of metagenomic sequences using interpolated Markov models.


**Categories:** metagenomics, sequence-clustering, unsupervised-learning  
**Publication:** [PMC3098094](https://pmc.ncbi.nlm.nih.gov/articles/PMC3098094/)



(transtermhp)=
## [TransTermHP](https://transterm.ccb.jhu.edu/)

A highly accurate program that finds rho-independent transcription terminators in bacterial genomes. The site includes a database with pre-computed predictions for hundreds of species.


**Categories:** transcription-termination, bacterial-genomics, genome-annotation  
**Publication:** [PMC1852404](https://pmc.ncbi.nlm.nih.gov/articles/PMC1852404/)



(diamund)=
## [Diamund](https://github.com/salzberg-lab/diamund/wiki)

Diamund is an efficient algorithm for variant detection in family trios or pairs of closely related exome or whole-genome sequencing samples. It compares DNA sequences directly to one another, without aligning them to the reference genome.


**Categories:** variant-calling, family-trio, exome, wgs  
**Publication:** [PMC4031744](https://pmc.ncbi.nlm.nih.gov/articles/PMC4031744/)



(enterix)=
## [EnteriX](https://enterix.cbcb.umd.edu/)

Web servers for displaying alignments and annotations of bacterial genomes.

**Categories:** bacterial-genomics, genome-annotation  
**Publication:** [PMC168958](https://pmc.ncbi.nlm.nih.gov/articles/PMC168958/)



(pebls)=
## [PEBLS](https://github.com/salzberg-lab/pebls/)

PEBLS: Parallel Exemplar-Based Learning System

**Categories:** machine-learning  



(oc1)=
## [OC1](https://github.com/salzberg-lab/oc1)

The OC1 decision tree system

**Categories:** machine-learning
