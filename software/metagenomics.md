(choosing-a-metagenomics-classifier)=
## [How to Choose a Metagenomics Classifier](https://github.com/salzberg-lab/choosing-a-metagenomics-classifier/wiki)

A guide to choosing among Kraken, KrakenUniq, Kraken2, and Centrifuge, metagenomic classifiers developed by researchers in the Center for Computational Biology. The page provides comparisons of the tools and descriptions of the authors and their roles in software development.


**Categories:** metagenomics, classification, benchmarking  



(kraken)=
## [Kraken](https://github.com/dpuiu/kraken/wiki)

Kraken is a very fast system for taxonomic classification of short or long DNA sequences from a microbiome or metagenomic sample. KrakenUniq is a newer, more capable version of Kraken1, and users are strongly recommended to upgrade to KrakenUniq or Kraken2.


**Categories:** metagenomics, classification, taxonomic-classification  
**Publication:** [PMC4053813](https://pmc.ncbi.nlm.nih.gov/articles/PMC4053813/)



(krakenuniq)=
## [KrakenUniq](https://github.com/fbreitwieser/krakenuniq/wiki)

KrakenUniq is an update to Kraken 1 that runs as fast as Kraken and can work with the same databases, but additionally counts the number of unique k-mers using the stream sketching algorithm HyperLogLog. Using unique k-mers, results can be filtered and ranked by genome coverage rather than simple read counts. A newer version developed by Christopher Pockrandt can run on low-memory machines, including laptops, even with very large databases. It is also available through Bioconda at https://anaconda.org/bioconda/krakenuniq.


**Categories:** metagenomics, classification, taxonomic-classification, abundance-estimation  
**Publication:** [PMC6238331](https://pmc.ncbi.nlm.nih.gov/articles/PMC6238331/)



(kraken2)=
## [Kraken2](https://github.com/DerrickWood/kraken2/wiki)

Kraken2 is an improved version of Kraken, using the same classification algorithm with improvements in speed and memory usage. Kraken2 provides faster database build times, smaller database sizes, and faster classification speeds.


**Categories:** metagenomics, classification, taxonomic-classification  
**Publication:** [PMC6883579](https://pmc.ncbi.nlm.nih.gov/articles/PMC6883579/)



(centrifuge)=
## [Centrifuge](https://github.com/DaehwanKimLab/centrifuge/wiki)

Centrifuge is a very rapid and memory-efficient system for the classification of DNA sequences from microbial samples, with better sensitivity than and comparable accuracy to other leading systems. Centrifuge requires a relatively small index, such as 4.3 GB for about 4,100 bacterial genomes.


**Categories:** metagenomics, classification, taxonomic-classification  
**Publication:** [PMC5131823](https://pmc.ncbi.nlm.nih.gov/articles/PMC5131823/)



(bracken)=
## [Bracken](https://github.com/jenniferlu717/Bracken/wiki)

Bracken is a statistical method that computes the abundance of species from DNA sequences in a metagenomics sample.


**Categories:** metagenomics, abundance-estimation, taxonomic-classification  
**Publication:** [PMC12016282](https://pmc.ncbi.nlm.nih.gov/articles/PMC12016282/)



(pavian)=
## [Pavian](https://github.com/salzberg-lab/pavian/wiki)

Pavian is a web application for exploring metagenomics classification results, with a special focus on infectious disease diagnosis.


**Categories:** metagenomics, visualization, classification  
**Publication:** [PMC8215911](https://pmc.ncbi.nlm.nih.gov/articles/PMC8215911/)



(krakentools)=
## [KrakenTools](https://github.com/jenniferlu717/KrakenTools/wiki)

KrakenTools is a suite of scripts designed to be used alongside Kraken, KrakenUniq, Kraken2, or Bracken. The scripts help Kraken users perform downstream analysis of Kraken results.


**Categories:** metagenomics, classification, downstream-analysis  
**Publication:** [PMC9725748](https://pmc.ncbi.nlm.nih.gov/articles/PMC9725748/)
