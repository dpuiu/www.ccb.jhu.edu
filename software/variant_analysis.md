# Variant Analysis Tools 


(chasm-snvbox)=
## [CHASM and SNVBox](https://github.com/KarchinLab/CHASMplus)

Software to predict the functional significance of somatic missense mutations observed in the genomes of cancer cells, and a database of pre-computed features of all possible amino acid substitutions at every position of the annotated human exome.


**Categories:** variant-analysis, cancer, missense  
**Publication:** [PMC3137226](https://pmc.ncbi.nlm.nih.gov/articles/PMC3137226/)



(cravat)=
## [CRAVAT](https://www.cravat.us/)

Cancer-related analysis of variants toolkit. Web tool for functional predictions and annotations of both somatic and germline variants.


**Categories:** variant-analysis, cancer, annotation  
**Publication:** [PMC3582272](https://pmc.ncbi.nlm.nih.gov/articles/PMC3582272/)



(fast)=
## [FAST](https://bitbucket.org/baderlab/fast/wiki/Home)

An application for genome-wide studies by efficiently running several gene-based analysis methods simultaneously on the same data set.


**Categories:** variant-analysis, gene-based-analysis  
**Publication:** [PMC3720833](https://pmc.ncbi.nlm.nih.gov/articles/PMC3720833/)



(ls-snp-pdb)=
## [LS-SNP/PDB](https://ls-snp.icm.jhu.edu/)

Web tool for structural annotations and visualizations of missense variants in dbSNP.


**Categories:** variant-analysis, structural-analysis, missense  
**Publication:** [PMC6276889](https://pmc.ncbi.nlm.nih.gov/articles/PMC6276889/)



(mupit)=
## [muPIT](https://mupit.icm.jhu.edu/)

Web tool for interactive structural annotations and visualizations of non-synonymous variation and mutations on proteins.


**Categories:** variant-analysis, structural-analysis, missense  
**Publication:** [PMC3797853](https://pmc.ncbi.nlm.nih.gov/articles/PMC3797853/)
