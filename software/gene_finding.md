# Computational Gene Finding 


(eviann)=
## [EviAnn](https://github.com/alekseyzimin/EviAnn_release)

A novel genome annotation software package based entirely on experimental evidence. It derives protein-coding gene and long non-coding RNA (lncRNA) annotations from RNA-seq data and/or transcript sequences, together with alignments of proteins from related species.


**Categories:** gene-prediction, genome-annotation, rna-seq, transcript-annotation  
**Publication:** [PMC12132231](https://pmc.ncbi.nlm.nih.gov/articles/PMC12132231/)



(lifton)=
## [LiftOn](https://github.com/Kuanhao-Chao/LiftOn)

LiftOn combines DNA and protein alignments to improve genome annotation.


**Categories:** genome-annotation, gene-annotation, genome-assembly  
**Publication:** [PMC11874971](https://pmc.ncbi.nlm.nih.gov/articles/PMC11874971/)



(liftoff)=
## [Liftoff](https://github.com/agshumate/Liftoff)

Liftoff provides accurate mapping of gene annotations between genome assemblies. 


**Categories:** genome-annotation, gene-annotation, genome-assembly  
**Publication:** [PMC8289374](https://pmc.ncbi.nlm.nih.gov/articles/PMC8289374/)



(balrog)=
## [Balrog](https://github.com/salzberg-lab/Balrog)

Balrog is a universal protein model for prokaryotic gene prediction.


**Categories:** gene-prediction, protein, prokaryote  
**Publication:** [PMC7946324](https://pmc.ncbi.nlm.nih.gov/articles/PMC7946324/)



(orfanage)=
## [ORFanage](https://github.com/alevar/ORFanage)

ORFanage investigates open reading frames in known and novel transcripts.


**Categories:** gene-prediction, transcript-analysis, orf  
**Publication:** [PMC10718564](https://pmc.ncbi.nlm.nih.gov/articles/PMC10718564/)



(glimmer)=
## [Glimmer](https://github.com/salzberg-lab/glimmer/wiki)

A system that uses interpolated Markov models to find genes in microbial DNA. Used to annotate hundreds (possibly thousands) of bacterial, archaeal, and viral genomes. Current version is 3.02.


**Categories:** gene-prediction, prokaryote, microbial-genomics  
**Publication:** [PMC148753](https://pmc.ncbi.nlm.nih.gov/articles/PMC148753/)



(glimmerhmm)=
## [GlimmerHMM](https://github.com/salzberg-lab/glimmerhmm/wiki)

A Generalized Hidden Markov Model gene-finder which makes use of the techniques implemented previously by GlimmerM.


**Categories:** gene-prediction, eukaryote, hidden-markov-model  
**Publication:** [PMC1810558](https://pmc.ncbi.nlm.nih.gov/articles/PMC1810558/)



(glimmer-mg)=
## [Glimmer-MG](https://github.com/davek44/Glimmer-MG)

Glimmer-MG is an older system for finding genes in metagenomic shotgun DNA sequences, using the Glimmer algorithm plus the SCIMM system for clustering metagenomics data, and the now-outdated Phymm system for phylogenetic labeling.


**Categories:** gene-prediction, metagenomics, prokaryote  
**Publication:** [PMC3245904](https://pmc.ncbi.nlm.nih.gov/articles/PMC3245904/)



(genesplicer)=
## [GeneSplicer](https://github.com/salzberg-lab/genesplicer/wiki)

A fast system for detecting splice sites in genomic DNA of various eukaryotes.


**Categories:** gene-prediction, splice-sites, eukaryote  
**Publication:** [PMC29713](https://pmc.ncbi.nlm.nih.gov/articles/PMC29713/)



(jigsaw)=
## [JIGSAW](https://github.com/salzberg-lab/jigsaw/wiki)

A program that predicts gene models using the output from multiple sources of evidence, including other gene finders, BLAST searches, and other alignment data.


**Categories:** gene-prediction, genome-annotation, evidence-integration  
**Publication:** [PMC1810558](https://pmc.ncbi.nlm.nih.gov/articles/PMC1810558/)
