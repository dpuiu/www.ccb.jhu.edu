# Genome Assembly 


(mummer)=
## [MUMmer](https://github.com/mummer4/mummer)

A system for aligning whole genomes, chromosomes, and other very long DNA sequences. MUMmer is also widely used for comparing genome assemblies. MUMmer was hosted on SourceForge beginning in the early 2000s and moved to GitHub with the release of MUMmer4 in 2017.


**Categories:** genome-assembly, whole-genome-alignment, genome-comparison  
**Publication:** [PMC5802927](https://pmc.ncbi.nlm.nih.gov/articles/PMC5802927/)



(mummergpu)=
## [MUMmerGPU](https://mummergpu.sourceforge.net/)

An early attempt to use GPUs for alignment. MUMmerGPU uses a technique called general-purpose GPU programming (GPGPU programming) to harness the extreme parallelism of GPUs for non-graphics tasks.


**Categories:** genome-assembly, alignment, gpu  
**Publication:** [PMC2222658](https://pmc.ncbi.nlm.nih.gov/articles/PMC2222658/)



(gage)=
## [GAGE](https://gage.cbcb.umd.edu/)

A realistic assessment of genome assembly software in a rapidly changing field of next-generation sequencing.


**Categories:** genome-assembly, assembly-evaluation, benchmarking  
**Publication:** [PMC3290791](https://pmc.ncbi.nlm.nih.gov/articles/PMC3290791/)



(gage-b)=
## [GAGE-B](https://github.com/salzberg-lab/GAGE_B)

An evaluation of contiguity and accuracy of assemblies of bacterial organisms generated by some of the most commonly used genome assemblers. GAGE-B follows the standards set by GAGE.


**Categories:** genome-assembly, assembly-evaluation, benchmarking, bacteria  
**Publication:** [PMC3702249](https://pmc.ncbi.nlm.nih.gov/articles/PMC3702249/)



(masurca)=
## [MaSuRCA](https://github.com/alekseyzimin/masurca)

MaSuRCA is a whole-genome assembler developed originally at the University of Maryland by James Yorke, Aleksey Zimin, and their colleagues. Ongoing development is a joint effort between JHU and UMD, with recent modules designed to create hybrid assemblies using both short reads (Illumina) and long reads (PacBio/Oxford Nanopore).


**Categories:** genome-assembly, whole-genome-assembly, hybrid-assembly, short-read, long-read  
**Publication:** [PMC3799473](https://pmc.ncbi.nlm.nih.gov/articles/PMC3799473/)



(flash)=
## [FLASH](https://github.com/salzberg-lab/flash/wiki)

A fast, accurate program to increase the length of reads by overlapping and merging paired reads from fragments shorter than twice the length of reads. Primarily designed to merge Illumina paired reads.


**Categories:** read-merging, short-read, illumina  
**Publication:** [PMC3198573](https://pmc.ncbi.nlm.nih.gov/articles/PMC3198573/)



(jasper)=
## [JASPER](https://github.com/alguoo314/JASPER)

JASPER is a fast genome polishing tool that improves the accuracy of genome assemblies. 


**Categories:** genome-assembly, assembly-polishing  
**Publication:** [PMC10096238](https://pmc.ncbi.nlm.nih.gov/articles/PMC10096238/)



(amos)=
## [AMOS Assembler project](https://amos.sourceforge.net/)

A set of tools, libraries, and freestanding genome assemblers, all open source. AMOS is an open consortium started at The Institute for Genomic Research (TIGR) that grew to include the University of Maryland, Johns Hopkins University, the Karolinska Institutet, the Marine Biological Laboratory, and others.


**Categories:** genome-assembly, assembler  
**Publication:** [PMC3072823](https://pmc.ncbi.nlm.nih.gov/articles/PMC3072823/)



(amoscmp)=
## [AMOScmp](https://amos.sourceforge.net/docs/pipeline/AMOScmp.html)

A comparative genome assembler that uses one genome as a reference on which to assemble another, closely related species. 


**Categories:** genome-assembly, comparative-assembly  
**Publication:** [PMC3603210](https://pmc.ncbi.nlm.nih.gov/articles/PMC3603210/)



(minimus)=
## [MINIMUS](https://amos.sourceforge.net/docs/pipeline/minimus.html)

A small, lightweight assembler for small jobs such as assembling a viral genome, assembling a set of reads that match a single gene, or other tasks that do not require the complex infrastructure of a large-genome assembler.


**Categories:** genome-assembly, small-genome-assembly, assembler  
**Publication:** [PMC1821043](https://pmc.ncbi.nlm.nih.gov/articles/PMC1821043/)



(hawkeye)=
## [Hawkeye](https://amos.sourceforge.net/hawkeye/)

A visual analytics tool for genome assembly analysis and validation, designed to aid in identifying and correcting assembly errors. All levels of the assembly data hierarchy are made accessible to users, along with summary statistics and common assembly metrics. A ranking component guides investigation towards likely mis-assemblies or interesting features. Hawkeye can be used to interactively analyze assemblies from many popular assemblers on a desktop computer. 


**Categories:** genome-assembly, assembly-analysis, assembly-validation, visualization  
**Publication:** [PMC1868940](https://pmc.ncbi.nlm.nih.gov/articles/PMC1868940/)



(quake)=
## [Quake](https://github.com/davek44/Quake/wiki)

A software package to detect and correct substitution sequencing errors in WGS data sets with deep coverage.


**Categories:** sequencing-error-correction, short-read, wgs  
**Publication:** [PMC3156955](https://pmc.ncbi.nlm.nih.gov/articles/PMC3156955/)



(celera-assembler)=
## [Celera Assembler](https://wgs-assembler.sourceforge.net)

A whole-genome assembler originally developed at Celera Genomics for the assembly of the human genome. Celera Assembler is an open-source project at SourceForge. The code has been actively maintained since 2005 by researchers at CBCB and the Venter Institute, formerly known as TIGR, the Institute for Genomic Research.


**Categories:** genome-assembly, whole-genome-assembly, long-read  
**Publication:** [PMC2639302](https://pmc.ncbi.nlm.nih.gov/articles/PMC2639302/)



(abba)=
## [ABBA](https://amos.sourceforge.net/docs/pipeline/abba.html)

Assembly Boosted By Amino acid sequence is a comparative gene assembler that uses amino acid sequences from predicted proteins to help build a better assembly.


**Categories:** genome-assembly, comparative-assembly, gene-assembly  
**Publication:** [PMC2529408](https://pmc.ncbi.nlm.nih.gov/articles/PMC2529408/)



(autoeditor)=
## [AutoEditor](https://sourceforge.net/apps/mediawiki/amos/index.php?title=AutoEditor)

A tool for correcting sequencing and basecaller errors using sequence assembly and chromatogram data from Sanger (first-generation) reads. On average, AutoEditor corrects 80% of erroneous base calls, with an accuracy of 99.99%.


**Categories:** sequencing-error-correction, sanger, assembly  
**Publication:** [PMC373340](https://pmc.ncbi.nlm.nih.gov/articles/PMC373340/)
